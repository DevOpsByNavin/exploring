## shadcn/ui

- Standard in 2026. Not a dependency — copy-paste components (Radix primitives + Tailwind) that live in your repo.
- Beautiful by default, good accessibility (keyboard nav, screen reader via Radix).
- Heavily modifiable because you own the code. Requires Tailwind.

## Material-UI (MUI)

- By Google's Material spec, massive ecosystem.
- Heavy: large bundle + Emotion runtime; opinionated Google look unless heavily themed.

Also worth knowing: Mantine (batteries-included hooks), DaisyUI (Tailwind class shortcuts), Chakra UI (simple prop-style API).

Pick shadcn for custom design systems, MUI for enterprise admin panels with ready-made data grids.
