# Classic stacks

- **LAMP** = Linux / Apache / MySQL / PHP. The 2000s default (WordPress, Drupal, Laravel on shared hosting). Still alive for cheap content sites.
- **MERN** = MongoDB / Express / React / Node. The 2010s SPA default: JSON APIs + React frontend, no SQL.
- **MEAN** = MongoDB / Express / Angular / Node. Same as MERN with Angular instead of React (enterprise flavor).

What replaced them: meta-framework + Postgres (Next.js/Nuxt + Supabase/Neon/Prisma/Drizzle), or JAMstack (static + BaaS + edge functions) for content sites.
