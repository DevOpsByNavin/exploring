## Heroku

- No free tier
- Massive add-on marketplace

## Railway

- emerging as Heroku alternative
- Generous free tier

## Render

- Also supports Docker

## Koyeb

- Global deployment
- Container focused
- Built-in global scaling and load balancing

| Platform | Category | What it really allows to do |
|---|---|---|
| Heroku | Application PaaS | Applications deployed as managed dynos, with add-ons and supporting services |
| Railway | General-purpose application PaaS | Persistent services, containers, scheduled jobs and databases |
| Render | General-purpose application PaaS | Web services, containers, background workers, static sites and databases |
| Koyeb | Application PaaS / managed container platform | Web services, background workers and containerized applications |
| Coolify | Self-hosted PaaS / deployment control plane | Apps and containers running on infrastructure you manage |
