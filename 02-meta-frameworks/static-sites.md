## Hugo

- SSG written on **Go**
- You mostly write **.md** 
- and use Go template for layout
- Hugo then compiles into staic HTML/CSS/JS files.

**Features**

- super fast
- excellent for large site


## Docusaurus

- created by Meta
- React based documentation framework
- You write docs in **.md**/**.mdx**
- and it will give you polished docs with: search, theme, version, sidebar, etc.
