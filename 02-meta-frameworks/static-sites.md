## Hugo

- SSG written in **Go** (single binary, no JS runtime — that's why it's fast).
- You write **`.md`** + Go templates for layout.
- Hugo compiles to static HTML/CSS/JS.

**Best for:** thousands of Markdown pages (blogs, docs mirrors, marketing sites).

## Docusaurus

- Created by Meta. React-based docs framework.
- You write docs in **`.md` / `.mdx`** (Markdown + interactive React components).
- Gives you search, theming, versioning, sidebar out of the box.

**Best for:** versioned product docs. Pick Hugo for raw build speed / scale, Docusaurus for docs UX.
